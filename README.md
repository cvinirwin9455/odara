# Odara — Find the way forward

The AI-assisted career pathway platform for coaches.

## About

Odara helps coaches guide clients from career uncertainty to a clear, evidence-based way forward. It provides structured, AI-assisted tools that make career coaching more evidence-based, scalable, and practical.

## Deployment

This is a static landing page. Deploy it to any static hosting provider:

- **Netlify**: Drag and drop the folder, or connect this repo
- **Vercel**: Import this repo and deploy
- **GitHub Pages**: Enable Pages in repo settings, point to the root
- **Cloudflare Pages**: Connect this repo
- **Any web server**: Just serve the `index.html` file

## Waitlist Form

The waitlist form currently shows a confirmation message but doesn't send data anywhere. When you're ready to collect emails, replace the `handleSubmit` function in `index.html` with your preferred service:

- [Formspree](https://formspree.io)
- [Mailchimp](https://mailchimp.com)
- [ConvertKit](https://convertkit.com)
- A custom API endpoint (e.g., Supabase, Firebase)
